# Formato: pares de líneas.
#   en:  el texto EXACTO como está en el código, con sus %d y %s
#   tr:  la traducción, con los mismos %d y %s en el mismo orden
#
# Usa \n para un salto de línea. Las líneas que empiezan con # se ignoran.
# Lo que no esté aquí se muestra en inglés, así que se puede ir llenando
# poco a poco sin romper nada.
#
# Variedad: español de México, neutro para LATAM. "Agarrar", no "coger".
# "Tú", nunca "vos" ni "vosotros". Los nombres propios del bestiario y de
# los jefes NO se traducen: Goo, Tengu, Yog-Dzewa, Zot, DM-300, Otiluke.
#
# OJO: aquí sólo van cadenas COMPLETAS. El juego arma varias frases
# pegando trozos ("and ", "is cursed"), y traducir un trozo suelto da un
# español roto porque el orden de las palabras cambia. Esos se quedan en
# inglés a propósito hasta que la frase entera pase por un solo sitio.
